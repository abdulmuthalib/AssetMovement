## Understanding Prompt Coding

### What is Prompt Coding?

Prompt coding uses AI models to generate code from human-readable descriptions. Instead of writing code manually, you describe what you want:

**Traditional Approach:**
```
Developer writes 50 lines of code manually → Tests → Debugs
```

**Prompt Coding Approach:**
```
Developer writes prompt → Codex generates code → Developer reviews & refines
```

### Key Concepts

#### 1. **Prompts**
Clear, specific instructions you write to guide the AI. Quality prompts = quality code.

**Poor Prompt:**
```
"Create a login function"
```

**Good Prompt:**
```
"Create a React login component with email and password fields, form validation, 
error messages, and submit button. Use React hooks (useState) and include proper 
accessibility attributes (aria-labels)."
```

#### 2. **Completion**
The code generated by the AI based on your prompt.

#### 3. **Temperature & Parameters**
Controls how creative the AI is:
- **Lower (0.1-0.3)**: Predictable, consistent code (recommended for production)
- **Higher (0.7-1.0)**: Creative, diverse suggestions

### How Codex Differs from ChatGPT

| Feature | ChatGPT | Codex |
|---------|---------|-------|
| Primary Use | Conversation | Code generation |
| Code Understanding | Good | Excellent |
| Code Quality | Variable | Optimized |
| Integration | Limited | Via API |
| Speed | Moderate | Very fast |

1. Visit https://app.supabase.com
2. Click "New project"
3. Fill in project details:

1. In Supabase dashboard, go to **SQL Editor**
2. Click **New Query**
3. Run this SQL:

```sql
-- Create users table
CREATE TABLE users (
  id BIGSERIAL PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  username VARCHAR(50) UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Create projects table
CREATE TABLE projects (
  id BIGSERIAL PRIMARY KEY,
  user_id BIGINT REFERENCES users(id),
  title VARCHAR(255) NOT NULL,
  description TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

   - **Service Role Key**: Your private API key (keep secret!)

Create a `.env.local` file in your project root:

```

### Step 5: Install Supabase Client

```bash
npm install @supabase/supabase-js
```

### Step 6: Create Supabase Utility File

Create `src/utils/supabaseClient.js`:

```javascript
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL
const supabaseKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY

export const supabase = createClient(supabaseUrl, supabaseKey)

// Example: Fetch all users
export const getUsers = async () => {
  const { data, error } = await supabase
    .from('users')
    .select('*')
  
  if (error) console.error('Error fetching users:', error)
  return data
}

// Example: Create new user
export const createUser = async (email, username) => {
  const { data, error } = await supabase
    .from('users')
    .insert([{ email, username }])
  
  if (error) console.error('Error creating user:', error)
  return data
}

// Example: Update user
export const updateUser = async (id, updates) => {
  const { data, error } = await supabase
    .from('users')
    .update(updates)
    .match({ id })
  
  if (error) console.error('Error updating user:', error)
  return data
}

// Example: Delete user
export const deleteUser = async (id) => {
  const { data, error } = await supabase
    .from('users')
    .delete()
    .match({ id })
  
  if (error) console.error('Error deleting user:', error)
  return data
}
```

### Step 2: Install OpenAI Library

```bash

```

### Step 3: Create Codex Helper Function

Create `src/utils/codegenHelper.js`:

```javascript
import { Configuration, OpenAIApi } from "openai"

const configuration = new Configuration({
  apiKey: process.env.OPENAI_API_KEY,
})

const openai = new OpenAIApi(configuration)

/**
 * Generate code using Codex
 * @param {string} prompt - Natural language description
 * @param {number} maxTokens - Maximum tokens in response
 * @returns {string} Generated code
 */
export const generateCode = async (prompt, maxTokens = 500) => {
  try {
    const response = await openai.createCompletion({
      model: "code-davinci-002", // or "code-davinci-003"
      prompt: prompt,
      temperature: 0.3, // Lower = more predictable
      max_tokens: maxTokens,
      top_p: 1,
      frequency_penalty: 0,
      presence_penalty: 0,
    })

    return response.data.choices[0].text
  } catch (error) {
    console.error("Codex error:", error)
    throw error
  }
}

/**
 * Generate React component
 */
export const generateReactComponent = async (description) => {
  const prompt = `Create a React component that: ${description}
  
Use React hooks (useState, useEffect). Include proper styling and accessibility.
Return only the component code, no explanations.`

  return generateCode(prompt, 800)
}

/**
 * Generate JavaScript function
 */
export const generateFunction = async (description) => {
  const prompt = `Write a JavaScript function that: ${description}

Include proper error handling and comments. Return only the function code.`

  return generateCode(prompt, 600)
}

/**
 * Explain code
 */
export const explainCode = async (code) => {
  const prompt = `Explain this code in simple terms for beginners:

\`\`\`javascript
${code}
\`\`\`

Provide a clear, concise explanation.`

  return generateCode(prompt, 400)
}
```

### Step 4: Create API Endpoint for Code Generation

Create `src/pages/api/generateCode.js`:

```javascript
import { generateCode } from '../../utils/codegenHelper'

export default async function handler(req, res) {
  if (req.method !== 'POST') {
    return res.status(405).json({ error: 'Method not allowed' })
  }

  try {
    const { prompt } = req.body

    if (!prompt) {
      return res.status(400).json({ error: 'Prompt is required' })
    }

    const code = await generateCode(prompt)
    res.status(200).json({ code })
  } catch (error) {
    res.status(500).json({ error: error.message })
  }
}
```

### Step 5: Best Practices for Prompts

**DO:**
- ✅ Be specific and detailed
- ✅ Mention the language/framework
- ✅ Include desired error handling
- ✅ Specify performance requirements
- ✅ Provide examples when helpful

**DON'T:**
- ❌ Write vague descriptions
- ❌ Ask for entire applications at once
- ❌ Ignore security considerations
- ❌ Use very high temperatures for production code
- ❌ Trust generated code without review

**Example: Good Prompt**
```
Create a React form component with:
- Email and password input fields
- Form validation (email format, password length 8+)
- Loading state during submission
- Error message display
- Submit button disabled during loading
- Styled with Tailwind CSS

The component should accept an onSubmit callback.
Include proper accessibility attributes.
```

**Example: Row Level Security Policy**
```sql
-- Only allow users to see their own data
CREATE POLICY "Users can view own projects" 
ON projects 
FOR SELECT 
USING (auth.uid() = user_id);

-- Only allow inserting own projects
CREATE POLICY "Users can create own projects" 
ON projects 
FOR INSERT 
WITH CHECK (auth.uid() = user_id);
```

#### Phase 4: Build Main Page (1 hour)

**Step 4.1: Create Todo Page**

```javascript
// src/pages/todos.js
import { useEffect, useState } from 'react'
import TodoList from '../components/TodoList'
import AddTodoForm from '../components/AddTodoForm'

export default function TodosPage() {
  const [todos, setTodos] = useState([])
  const [loading, setLoading] = useState(true)

  useEffect(() => {
    fetchTodos()
  }, [])

  const fetchTodos = async () => {
    try {
      const res = await fetch('/api/todos')
      const data = await res.json()
      setTodos(data)
    } catch (error) {
      console.error('Error fetching todos:', error)
    } finally {
      setLoading(false)
    }
  }

  const handleAdd = async (title) => {
    try {
      const res = await fetch('/api/todos', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ title }),
      })
      const newTodo = await res.json()
      setTodos([...todos, newTodo])
    } catch (error) {
      console.error('Error adding todo:', error)
    }
  }

  const handleToggle = async (id, completed) => {
    try {
      const res = await fetch(`/api/todos/${id}`, {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ completed: !completed }),
      })
      const updated = await res.json()
      setTodos(todos.map(t => t.id === id ? updated : t))
    } catch (error) {
      console.error('Error updating todo:', error)
    }
  }

  const handleDelete = async (id) => {
    try {
      await fetch(`/api/todos/${id}`, { method: 'DELETE' })
      setTodos(todos.filter(t => t.id !== id))
    } catch (error) {
      console.error('Error deleting todo:', error)
    }
  }

  if (loading) return <div>Loading...</div>

  return (
    <div className="max-w-md mx-auto p-4">
      <h1 className="text-3xl font-bold mb-6">My Todos</h1>
      <AddTodoForm onAdd={handleAdd} />
      <TodoList 
        todos={todos}
        onToggle={handleToggle}
        onDelete={handleDelete}
      />
    </div>
  )
}
```

## Troubleshooting & FAQs

### GitHub Issues

**Problem: "Permission denied (publickey)"**
```bash
# Solution: Generate SSH key
ssh-keygen -t ed25519 -C "your-email@example.com"

# Add to GitHub: Settings → SSH Keys → New SSH Key
# Paste contents of ~/.ssh/id_ed25519.pub
```

**Problem: "Merge conflicts"**
```bash
# Before merging, sync with main
git fetch origin
git merge origin/main

# Resolve conflicts in VS Code
# Mark as resolved and commit
git add .
git commit -m "resolve merge conflicts"
```

### Supabase Issues

**Problem: "Row Level Security policy denies access"**
```sql
-- Enable public access (development only)
ALTER TABLE todos DISABLE ROW LEVEL SECURITY;

-- Or create proper policy
CREATE POLICY "Enable read for all users" 
ON todos 
FOR SELECT 
USING (true);
```

**Problem: "Foreign key constraint failed"**
```sql
-- Ensure parent record exists
-- Check that user_id references existing user in users table
SELECT * FROM users WHERE id = [user_id];
```

### OpenAI Codex Issues

**Problem: "Rate limit exceeded"**
- Solution: Wait a few minutes or upgrade account
- Check usage at https://platform.openai.com/account/usage/overview

**Problem: "Generated code has bugs"**
- Solution: Write more detailed prompts
- Always review and test generated code
- Use lower temperature (0.1-0.3) for production code

### Vercel Issues

**Problem: "Environment variables not working"**
- Solution: Redeploy after adding variables
- Make sure variables are in correct environment
- For NEXT_PUBLIC_*, commit changes and redeploy

**Problem: "Build fails in Vercel but works locally"**
- Solution: Check buildLogs in Vercel dashboard
- Ensure all dependencies are in package.json
- Check that environment variables are set

### Common Questions

**Q: Is Codex-generated code production-ready?**
A: No, always review, test, and audit generated code. Use it to accelerate development, not replace careful engineering.

**Q: Can I use Codex offline?**
A: No, Codex requires API connection. Consider local alternatives like Ollama for offline use.

**Q: How much does this stack cost?**
A: Most services have generous free tiers. Costs start when you exceed limits (GitHub ~$21/month for teams, Supabase ~$25/month for production, Vercel free for small projects, OpenAI ~$0.02-0.20 per 1K tokens).

**Q: How do I keep my API keys secure?**
A: Use `.env.local` (never commit), Vercel environment variables, and Row Level Security on Supabase.

**Q: Can I use other AI models instead of Codex?**
A: Yes! You can use GPT-4, Claude, or others by changing the API integration, but you'll need to adjust prompts for each model.
